## 1. 安装

首先，安装 Socket.IO 客户端库，具体安装方式取决于您选择的编程语言：

- **JavaScript**: 使用 [socket.io-client](https://github.com/socketio/socket.io-client) 库。
- **Java**: 可以使用 [socket.io-client-java](https://github.com/socketio/socket.io-client-java) 库。
- **C++**: 使用 [socket.io-client-cpp](https://github.com/socketio/socket.io-client-cpp) 库。
- **Swift**: 可以使用 [socket.io-client-swift](https://github.com/socketio/socket.io-client-swift) 库。
- **Dart**: 使用 [socket.io-client-dart](https://github.com/rikulo/socket.io-client-dart) 库。
- **Python**: 可以使用 [python-socketio](https://github.com/miguelgrinberg/python-socketio) 库。
- **.NET**: 使用 [socket.io-client-csharp](https://github.com/doghappy/socket.io-client-csharp) 库。
- **Rust**: 可以使用 [rust-socketio](https://github.com/1c3t3a/rust-socketio) 库。
- **PHP**: 使用 [elephant.io](https://github.com/ElephantIO/elephant.io) 库。

## 2. 连接 Socket.IO 服务器

连接到 **Paobu 命名空间** `/paobu`（不是 `/tools`）：

```javascript
import { io } from 'socket.io-client';

const socket = io('https://gs.classtao.cn/paobu', {
  transports: ['websocket'],
});

socket.on('connect', () => {
  socket.emit('join', { roomId: '<与场端一致的 roomId>' });
});
```

| 配置项 | 说明 |
|--------|------|
| 服务器地址 | 基址 + `/paobu`，例如 `https://gs.classtao.cn/paobu` |
| `roomId` | 与场端 sprint 配置中的 `room_id` 或硬件 ID 一致 |
| 传输方式 | 建议 `transports: ['websocket']` |
| 重连 | 断线重连后 **必须再次发送 `join`** |

## 3. 推荐流程

```
connect → join
    → 收到 state_join_gpu（计时端在线）
    → control（setRunType）→ 收到 setRunType_report（success 为真）
    → 等待 person_in / face_recognition_result 等起点状态
    → start → 陆续收到 score → 收到 end 汇总
    → control（clearRunType）→ 收到 clearRunType_report，回到空闲
```

**注意：** 发令前必须先 **启用起点（setRunType）**，不能直接 `join` 后立即 `start`。

## 4. 发送消息

客户端可以向服务器发送以下类型的消息，每种消息类型都有其特定的作用和参数要求。

### 4.1. join

**作用：** 加入房间，与场端计时设备同属一场。

**参数字段说明：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `roomId` | 字符串 (String) | 房间的唯一标识符，须与场端一致 |

**参数示例：**

```json
{
  "roomId": "2e135416c5bbb9d1f6a9be61a1130d1f"
}
```

### 4.2. control

**作用：** 控制场端启用或释放跑步项目（预备 / 收工）。

**顶层参数字段：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `roomId` | 字符串 (String) | 房间 ID |
| `action` | 字符串 (String) | `"setRunType"` 启用距离；`"clearRunType"` 释放项目 |
| `data` | 对象 (Object) | 见下表 |

**当 `action` = `"setRunType"` 时，`data` 字段：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `runType` | 字符串 (String) | 项目类型：`FIFTY_M`、`SIXTY_M`、`HUNDRED_M`、`TWO_HUNDRED_M`、`FOUR_HUNDRED_M` |

**当 `action` = `"clearRunType"` 时，`data` 传空对象 `{}`。**

**示例 — 启用 50 米：**

```javascript
socket.emit('control', {
  roomId: '77ab1561029ec3645554a71c70701e2c',
  action: 'setRunType',
  data: { runType: 'FIFTY_M' },
});
```

**示例 — 释放项目：**

```javascript
socket.emit('control', {
  roomId: '77ab1561029ec3645554a71c70701e2c',
  action: 'clearRunType',
  data: {},
});
```

**应答：** 监听 `setRunType_report` / `clearRunType_report`（或通用 `report`），检查 `data.success` 与 `message`。

### 4.3. start

**作用：** 发令开始分道跑（须先成功 `setRunType`）。

**参数字段说明：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `roomId` | 字符串 (String) | 房间 ID |
| `runType` | 字符串 (String) | 与当前已启用的距离一致 |
| `users` | 数组 (Array) | 参赛用户列表，至少 1 条 |
| `users.runway_number` | 整数 (Integer) | 跑道号，从 1 开始 |
| `users.name` | 字符串 (String) | 用户姓名 |
| `users.extra_id` | 字符串 (String) | 额外 ID（学号等），无则传 `""` |

**参数示例：**

```json
{
  "roomId": "77ab1561029ec3645554a71c70701e2c",
  "runType": "FIFTY_M",
  "users": [
    {"runway_number": 1, "name": "黄晓旭", "extra_id": "1"},
    {"runway_number": 2, "name": "曹茗", "extra_id": "2"},
    {"runway_number": 3, "name": "朱强", "extra_id": "3"}
  ]
}
```

**JavaScript 示例：**

```javascript
socket.emit('start', {
  roomId: '77ab1561029ec3645554a71c70701e2c',
  runType: 'FIFTY_M',
  users: [
    { runway_number: 1, name: '黄晓旭', extra_id: '1' },
    { runway_number: 2, name: '曹茗', extra_id: '2' },
    { runway_number: 3, name: '朱强', extra_id: '3' },
  ],
});
```

### 4.4. end

**作用：** 强制结束本场，服务器返回全场成绩汇总。

**参数字段说明：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `roomId` | 字符串 (String) | 房间 ID |

**参数示例：**

```json
{
  "roomId": "77ab1561029ec3645554a71c70701e2c"
}
```

**JavaScript 示例：**

```javascript
socket.emit('end', { roomId: '77ab1561029ec3645554a71c70701e2c' });
```

## 5. 监听消息

### 5.1. 连接与设备状态

| 事件名 | 说明 |
|--------|------|
| `connect` / `disconnect` | 网页与服务器通断 |
| `state_join_gpu` | 计时端（GPU）上线，可提示「设备在线」 |
| `state_disconnect_gpu` | 计时端离线或不可用 |

```javascript
socket.on('state_join_gpu', () => {
  console.log('计时端在线');
});

socket.on('state_disconnect_gpu', () => {
  console.warn('计时端离线');
});
```

### 5.2. 成绩与全场结束

| 事件名 | 说明 |
|--------|------|
| `score` | 单次冲线成绩 |
| `end` | 本场结束，含 `status` 成绩汇总数组 |

### 5.3. 报告类（*_report）

除独立事件外，也可监听通用 `report`。解析载荷中的 `action` 与 `data`。

| 事件名 | 说明 |
|--------|------|
| `setRunType_report` | 启用距离结果，`data.success` 为真表示成功 |
| `clearRunType_report` | 释放项目结果 |
| `person_in_report` | 起点检测到人员进入 |
| `person_out_report` | 起点人员离开 |
| `start_line_state_report` | 起点状态（正常 / 踩线 / 抢跑等）；`data.name` 为跑道号 |
| `face_recognition_result_report` | 人脸识别；`data.name` 为学生姓名，跑道用 `runway_number` / `runway_name`（勿用 `start_camera`） |
| `runway_change_report` | 已识别选手换道（场端 ≥ `1.0.20260616140945`） |

**`face_recognition_result` 示例（新场端）：**

```json
{
  "action": "face_recognition_result",
  "data": {
    "name": "曹铭",
    "extra_id": "1",
    "runway_number": 2,
    "runway_name": "2",
    "start_camera": "1,2,3,4",
    "score": 0.586
  }
}
```

**`runway_change` 示例：**

```json
{
  "action": "runway_change",
  "data": {
    "from_name": "1",
    "to_name": "2",
    "from_runway_number": 1,
    "to_runway_number": 2,
    "user_name": "曹铭",
    "extra_id": "1"
  }
}
```

换道时可能先收到 `person_out` / `person_in`，以 `runway_change` 为准更新绑定。

```javascript
socket.on('setRunType_report', (payload) => {
  const success = payload?.data?.success;
  const message = payload?.data?.message ?? payload?.message;
  console.log('设距离结果', success, message);
});

socket.on('person_in_report', (p) => console.log('人员进入', p));
socket.on('face_recognition_result_report', (p) => console.log('人脸识别', p));
```

### 5.4. score

**作用：** 更新跑步实时成绩（每次冲线推送一条）。

**参数字段说明：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `number` | 整数 (Integer) | 名次，第几名 |
| `user` | 对象 (Object) | 选手信息 |
| ├─ `runway_number` | 整数 (Integer) | 跑道号，从 1 开始 |
| ├─ `name` | 字符串 (String) | 用户姓名 |
| ├─ `extra_id` | 字符串 (String) | 额外 ID |
| `ranking` | 整数 (Integer) | 跑道序号，第几道 |
| `time` | 浮点数 (Float) | 完成用时（秒） |
| `image` | 字符串 (String) | 冲线图片，base64 |
| `status` | 整数 (Integer) | 0 正常、1 踩线、2 抢跑 |
| `roomId` | 字符串 (String) | 房间 ID |

**参数示例：**

```json
{
  "number": 2,
  "user": {
    "runway_number": 1,
    "name": "黄晓旭",
    "extra_id": "1"
  },
  "ranking": 1,
  "time": 0.59,
  "image": "sfsdfsf",
  "status": 0,
  "roomId": "77ab1561029ec3645554a71c70701e2c"
}
```

### 5.5. end

**作用：** 本场结束，返回全场成绩汇总。

**参数字段说明：**

| 参数字段 | 类型 | 说明 |
|----------|------|------|
| `sport` | 字符串 (String) | 运动项目，此处为 `"paobu"` |
| `status` | 数组 (Array) | 所有选手成绩列表 |
| ├─ `name` | 字符串 (String) | 跑道标识名称 |
| ├─ `number` | 整数 (Integer) | 跑道号 |
| ├─ `user` | 对象或 null | 选手信息，null 表示未绑定 |
| │  ├─ `runway_number` | 整数 (Integer) | 跑道号 |
| │  ├─ `name` | 字符串 (String) | 姓名 |
| │  ├─ `extra_id` | 字符串 (String) | 额外 ID |
| ├─ `ranking` | 整数 (Integer) | 名次 |
| ├─ `time` | 浮点数 (Float) | 用时（秒） |
| ├─ `status` | 整数 (Integer) | 0 正常、1 踩线、2 抢跑 |
| `roomId` | 字符串 (String) | 房间 ID |

**参数示例：**

```json
{
  "sport": "paobu",
  "status": [
    {"name": "No.4", "number": 4, "user": null, "ranking": 1, "time": 0.02, "status": 0},
    {"name": "No.1", "number": 1, "user": {"runway_number": 1, "name": "黄晓旭", "extra_id": "1"}, "ranking": 2, "time": 0.59, "status": 0},
    {"name": "No.2", "number": 2, "user": {"runway_number": 2, "name": "曹茗", "extra_id": "2"}, "ranking": 3, "time": 1.33, "status": 0},
    {"name": "No.5", "number": 5, "user": null, "ranking": 4, "time": 6.81, "status": 0},
    {"name": "No.3", "number": 3, "user": {"runway_number": 3, "name": "朱强", "extra_id": "3"}, "ranking": 5, "time": 7.41, "status": 0}
  ],
  "roomId": "77ab1561029ec3645554a71c70701e2c"
}
```
